### 计算方法
- **水面线计算**: 基于曼宁公式和逐步推算法
- **弗劳德数**: Fr = V/√(gD)，其中V为流速，D为水深
- **流态判断**: Fr<1亚临界流，Fr=1临界流，Fr>1超临界流
