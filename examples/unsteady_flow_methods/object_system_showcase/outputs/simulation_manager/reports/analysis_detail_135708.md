## 工程建议

1. 对实时调度要求较高的场景，优先选择滞后时间短的方法；
2. 若需要严格控制水量守恒，应结合断面序列选择连续性误差最低的方案；
3. 对纵向梯度较大的渠道，可叠加更精细的模型进一步复核。
