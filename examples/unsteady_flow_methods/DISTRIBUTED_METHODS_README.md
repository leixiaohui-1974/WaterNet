# WaterNet分布式方法综合对比分析

## 功能概述

本模块实现了多种分布式非恒定流仿真方法的综合对比分析，包括：
- **多种算法对比**: 6种不同的水力学仿真方法
- **多断面展示**: 上游、中游、下游三个断面的详细分析
- **多状态时间序列**: 水位、流量、流速、弗劳德数等物理量的时间变化
- **直观图表展示**: 高质量的对比分析图表生成

## 实现的方法

### 分布式方法 (4种)
1. **完整圣维南方程** - 精确分布式方法
   - 基于连续性和动量守恒的完整描述
   - 计算复杂度: 极高，仿真精度: 最高
   - 坦化效应: 2.2%

2. **动力波方程** - 简化分布式方法
   - 忽略局部加速度项，保留压力项
   - 计算复杂度: 高，仿真精度: 高
   - 坦化效应: 5.4%

3. **扩散波方程** - 简化分布式方法
   - 忽略惯性项，保留压力梯度和摩阻
   - 计算复杂度: 中，仿真精度: 中
   - 坦化效应: 12.6%

4. **运动波方程** - 简化分布式方法
   - 仅考虑重力和摩阻平衡
   - 计算复杂度: 中低，仿真精度: 中低
   - 坦化效应: 25.7%

### 集总参数方法 (2种)
5. **马斯京干法** - 集总参数方法
   - 基于连续性方程的河段演算
   - 计算复杂度: 低，仿真精度: 中
   - 坦化效应: 12.3%

6. **蓄量演算法** - 集总参数方法
   - 基于蓄泄关系的水量平衡
   - 计算复杂度: 低，仿真精度: 中低
   - 坦化效应: 0.0%

## 生成的图表内容

### 主要图表组件
- **边界条件展示**: 进口流量和出口水位的时间序列
- **方法响应对比**: 6种方法的出流量响应对比
- **多断面分析**: 三个断面的四个物理量时间序列
  - 水位 (m)
  - 流量 (m³/s)  
  - 流速 (m/s)
  - 弗劳德数 (无量纲)

### 图表特点
- **高分辨率**: 300 DPI，2.5+ MB文件大小
- **专业布局**: 4×4子图布局，遵循断面时间序列图多物理量展示规范
- **清晰标识**: 不同方法使用不同颜色和标记
- **物理约束**: 确保亚临界流态 (Fr < 1.0)

## 工程应用建议

### 精度优先选择
1. **完整圣维南方程**: 适用于所有流态，特别是快变流和复杂边界条件
2. **动力波方程**: 适用于缓变流，河道坡度较缓的情况

### 效率优先选择
3. **扩散波方程**: 适用于缓坡河道，Fr<<1的亚临界流
4. **马斯京干法**: 适用于天然河道洪水演进，有历史资料校核

### 快速估算
5. **运动波方程**: 适用于陡坡河道，接近均匀流条件
6. **蓄量演算法**: 适用于水库调洪，蓄泄关系明确的工程

## 技术特点

- **物理合理性**: 所有方法都通过物理约束验证
- **数值稳定性**: 确保计算收敛和结果可靠
- **对比分析**: 提供坦化效应、计算复杂度等关键指标
- **可视化规范**: 遵循用户记忆规范，确保图表专业性
