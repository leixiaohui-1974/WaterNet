# 恒定流多工况水头损失分析示例

## 概述

本示例基于WaterNet项目中的复杂梯形断面明渠配置，演示如何计算和分析不同流量工况下的恒定流水面线和渠道水头损失。这是水利工程中的经典问题，对于渠道设计、运行调度和损失评估具有重要意义。

## 使用的配置文件

配置文件：`examples/configs/complex_channel.yaml`

该配置定义了一个1000米长的复杂梯形断面明渠，具有以下特点：

| 断面 | 里程(m) | 底高程(m) | 底宽(m) | 边坡系数 | 糙率系数 |
|------|---------|-----------|---------|----------|----------|
| 1    | 0.0     | 100.00    | 8.0     | 2.0      | 0.030    |
| 2    | 250.0   | 99.75     | 9.0     | 1.8      | 0.028    |
| 3    | 500.0   | 99.50     | 10.0    | 1.5      | 0.027    |
| 4    | 750.0   | 99.25     | 11.0    | 1.2      | 0.025    |
| 5    | 1000.0  | 99.00     | 12.0    | 1.0      | 0.025    |

渠道特点：
- 总长度：1000 m
- 平均坡度：0.001 (1‰)
- 断面形式：变化的梯形断面
- 糙率系数：0.025-0.030 (土质渠道)

## 分析工况

程序设置了三种典型流量工况：

| 工况名称 | 流量 (m³/s) | 应用场景 |
|----------|-------------|----------|
| 低流量   | 10.0        | 枯水期或基本生态流量 |
| 中流量   | 25.0        | 正常运行流量 |
| 高流量   | 50.0        | 丰水期或设计流量 |

边界条件：
- 下游水位：100.5 m (固定边界)
- 上游水位：由恒定流计算确定

## 计算结果分析

### 总体结果

根据计算结果，三种工况下的水头损失如下：

| 工况 | 流量(m³/s) | 上游水位(m) | 下游水位(m) | 总水头损失(m) | 单位损失(m/km) |
|------|------------|-------------|-------------|---------------|----------------|
| 低流量 | 10.0 | 101.002 | 100.500 | 0.502 | 0.502 |
| 中流量 | 25.0 | 101.598 | 100.500 | 1.098 | 1.098 |
| 高流量 | 50.0 | 102.280 | 100.500 | 1.780 | 1.780 |

### 关键发现

1. **损失规律**：
   - 流量从10 m³/s增加到25 m³/s（2.5倍），损失从0.502 m增加到1.098 m（2.19倍）
   - 流量从25 m³/s增加到50 m³/s（2倍），损失从1.098 m增加到1.780 m（1.62倍）
   - 符合摩擦损失与流速平方成正比的水力学规律

2. **分段分析**：
   - 第4分段（750-1000m）在高流量工况下损失最大（0.625 m）
   - 这与该段较小的边坡系数（1.0）和较大的流速（2.469 m/s）相关
   - 第1分段由于糙率系数最大（0.030），在低流量时损失占比较高

3. **流速分布**：
   - 随着渠道下游断面增大，流速呈递减趋势
   - 高流量工况下最大流速达到2.469 m/s（第5断面）

### 工程意义

1. **设计优化**：
   - 可以根据损失分布优化断面设计
   - 重点关注损失较大的分段

2. **运行调度**：
   - 在不同流量下预估水位和损失
   - 为泵站运行和水位控制提供依据

3. **能耗评估**：
   - 水头损失直接关系到输水能耗
   - 可用于经济性分析和优化

## 代码结构

### 主要类：`SteadyFlowHeadLossAnalyzer`

主要方法：

1. `_load_channel_config()`: 加载YAML配置文件
2. `_create_cross_section_functions()`: 创建梯形断面的水力几何函数
3. `_create_saint_venant_model()`: 构建圣维南模型
4. `calculate_steady_flow_cases()`: 计算所有工况的恒定流
5. `analyze_head_losses()`: 分析水头损失分布
6. `export_results_to_csv()`: 导出CSV数据
7. `generate_text_report()`: 生成文本报告

### 核心计算

使用WaterNet的`SaintVenantModel.compute_steady_state()`方法：

```python
steady_result = self.model.compute_steady_state(
    Q=Q,  # 流量
    downstream_H=self.downstream_water_level  # 下游边界水位
)
```

该方法基于：
- 标准步进法
- 能量方程
- 曼宁公式
- 数值迭代求解

### 水力计算

对于梯形断面，关键计算包括：

1. **过水断面积**：
   ```
   A = b×h + m×h²
   ```

2. **水面宽度**：
   ```
   T = b + 2×m×h
   ```

3. **湿周**：
   ```
   P = b + 2×h×√(1+m²)
   ```

4. **水力半径**：
   ```
   R = A/P
   ```

其中：b为底宽，h为水深，m为边坡系数

## 扩展功能

### 不同边界条件

修改下游水位可研究不同边界条件的影响：

```python
self.downstream_water_level = 101.0  # 提高下游水位
```

### 配置文件适配

程序可适配任何符合格式的梯形断面渠道配置文件。

## 注意事项

1. **收敛性**：对于极端流量或不合理的几何参数，可能出现数值不收敛
2. **适用范围**：适用于明渠均匀流和非均匀流，不适用于有压流
3. **精度**：基于一维圣维南方程，对于复杂几何形状可能有误差
4. **边界条件**：需要合理设置边界条件确保计算稳定
