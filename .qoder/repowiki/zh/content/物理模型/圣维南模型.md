## 简介
圣维南模型是基于圣维南方程组的一维明渠非恒定流模型，用于精确模拟水体在河道中的流动行为。该模型实现了完整的物理水力学方程，包括连续性方程和动量方程，并采用Preissmann四点隐式差分格式进行离散化，以确保数值计算的稳定性和精度。模型支持恒定流和非恒定流计算，具备统一的模型接口、增强的数值求解器、内置求解器选择、高级误差处理和性能监控功能。

## 核心实现原理
圣维南模型的核心在于求解一维非恒定流的圣维南方程组，包括连续性方程和动量方程。连续性方程描述了质量守恒，即∂A/∂t + ∂Q/∂x = 0，其中A是过水断面面积，Q是流量，t是时间，x是空间坐标。动量方程描述了动量守恒，即∂Q/∂t + ∂(Q²/A)/∂x + gA∂H/∂x + gA(Sf - S0) = 0，其中g是重力加速度，H是水位，Sf是摩阻坡度，S0是河床坡度。模型采用Preissmann四点隐式差分格式对这些偏微分方程进行离散化，将连续的时空域转换为离散的网格点，从而可以使用数值方法求解。

## 初始化与几何验证
模型的初始化过程首先验证输入参数的有效性，确保断面数据充足且格式正确。具体来说，模型要求至少有两个断面来定义明渠，并且每个断面数据必须包含里程桩号、底高程、曼宁糙率系数、面积函数和水面宽函数等必需字段。此外，面积函数和水面宽函数必须是可调用的函数对象。初始化过程中，模型会按里程对断面进行排序，并存储上游和下游边界节点的名称。这一过程确保了模型输入数据的完整性和一致性，为后续的计算奠定了基础。

## 内部节点与分段生成
模型根据断面数据自动生成内部计算节点和分段。内部节点的命名规则为{model_name}_internal_{index}，分段流量的命名规则为Q_{model_name}_seg_{index}。对于n个断面，模型会生成n-2个内部节点（不包括首末断面）和n-1个分段。每个分段的属性包括长度、平均坡度和平均糙率，这些属性通过相邻断面的几何数据计算得出。分段长度为相邻断面里程的绝对差值，平均坡度为高程差与长度的比值，平均糙率为相邻断面糙率的算术平均值。这一机制使得模型能够自动处理复杂的河道几何，无需手动指定内部节点和分段。

## 恒定流计算
恒定流计算采用标准步进法从下游向上游逐段计算恒定流水面线，基于能量方程和曼宁公式。计算过程首先设置下游边界条件，然后从下游向上游逐段求解上游水位。对于每个分段，模型使用二分法求解能量方程残差函数，以确定上游水位。能量方程考虑了上下游断面的水力要素、流速、水力半径、摩阻损失等因素。计算完成后，模型会构建结果字典，包含所有断面的水位、所有分段的流量和总蓄水量。此方法确保了恒定流计算的物理合理性和数值稳定性。

## 非恒定流方程构建
非恒定流方程的构建通过`get_equations`方法实现，该方法返回一个方程残差字典。模型为每个分段构建连续性方程和动量方程的离散化形式，采用Preissmann四点隐式差分格式。连续性方程的残差由时间导数项和空间导数项组成，动量方程的残差包括时间导数项、对流项、压力项和摩阻项。此外，模型还会为每个内部节点构建流量平衡方程，确保流入等于流出。这些方程共同构成了一个非线性方程组，可以通过数值方法求解，以获得非恒定流的动态响应。

## 模型变量管理
模型通过`get_variable_names`方法获取所有变量名列表，包括各分段流量变量和内部节点水位变量。分段流量变量的命名格式为Q_{model_name}_seg_{index}，内部节点水位变量的命名格式为H_{node_name}。这些变量名在联合求解系统中作为未知数，确保了模型变量的唯一性和可追溯性。变量管理机制使得模型能够与其他水力模型无缝集成，支持复杂的水系统仿真。

## 数值稳定性与边界条件
模型通过多种机制确保数值稳定性，包括自适应时间步长、质量守恒检查和收敛性监控。边界条件的设置灵活多样，支持上游流量边界和下游水位边界。上游流量可以是恒定值或时间序列，下游水位同样可以是恒定值或时间序列。模型还支持增强型求解器，通过`create_enhanced_solver`和`solve_with_enhanced_solver`方法提供更高级的数值求解能力。这些功能使得模型能够处理复杂的非恒定流问题，保证了仿真结果的准确性和可靠性。

## 代码调用示例
以下代码示例展示了如何创建圣维南模型、计算恒定流和构建非恒定流方程。首先，定义断面几何数据，包括里程、底高程、糙率、面积函数和水面宽函数。然后，创建圣维南模型实例，调用`compute_steady_state`方法计算恒定流水面线。最后，使用`get_equations`方法构建非恒定流方程的残差字典。这些示例代码为用户提供了清晰的调用指南，便于快速上手和应用模型。

```python
# 定义断面几何数据
sections = [
    {
        'mileage': 0.0,
        'elevation': 100.0,
        'roughness': 0.025,
        'area_func': lambda h: max(0, h - 100) * 10,
        'top_width_func': lambda h: 10 if h > 100 else 0
    },
    {
        'mileage': 1000.0,
        'elevation': 99.0,
        'roughness': 0.025,
        'area_func': lambda h: max(0, h - 99) * 10,
        'top_width_func': lambda h: 10 if h > 99 else 0
    }
]

# 创建圣维南模型
model = SaintVenantModel("TestChannel", "upstream", "downstream", sections)

# 计算恒定流
result = model.compute_steady_state(Q=10.0, downstream_H=100.5)

# 构建非恒定流方程
variables = {'H_upstream': 100.5, 'H_downstream': 99.2, 'Q_TestChannel_seg_0': 5.0}
prev_states = {'H_section_0': 100.4, 'H_section_1': 99.1, 'Q_TestChannel_seg_0': 4.8}
equations = model.get_equations(variables, dt=60.0, prev_states=prev_states)
```
