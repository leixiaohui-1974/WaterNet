## 传递函数矩阵理论体系

四方程IDZ模型采用2×2传递函数矩阵描述双节点系统：

```
[Q1_out]   [G11(s) G12(s)] [ΔQ1_in]   [Q0_up  ]
[Q2_out] = [G21(s) G22(s)] [ΔQ2_in] + [Q0_down]
```

该矩阵结构实现了上下游节点间的完整耦合关系，能够精确描述正向传播、回水效应和局部调蓄等复杂水力现象。模型通过将非线性系统在平衡点附近进行线性化处理，使用传递函数矩阵作用于输入扰动向量，最终输出为线性响应与平衡点偏移的叠加。

## 四个传递函数的物理意义与动态特性

### G11(s): 上游输入 → 上游输出（本地响应）
- **物理意义**：描述上游节点的本地响应特性
- **动态特性**：无延迟（T11 = 0），快速响应
- **参数影响**：τ11和α11共同控制响应速度和超调量

### G12(s): 下游输入 → 上游输出（回水效应）
- **物理意义**：描述回水效应，即下游条件对上游的影响
- **动态特性**：有延迟（T12 > 0），反向传播
- **参数影响**：τ12、T12和α12共同描述回水传播特性

### G21(s): 上游输入 → 下游输出（正向传播）
- **物理意义**：描述洪峰从上游向下游的正向传播过程
- **动态特性**：具有最大延迟（T21 > T12），为主要传播路径
- **参数影响**：τ21、T21和α21控制传播速度和衰减特性

### G22(s): 下游输入 → 下游输出（本地响应）
- **物理意义**：描述下游节点的本地响应和局部调蓄特性
- **动态特性**：无延迟（T22 = 0），体现局部调蓄能力
- **参数影响**：τ22和α22共同描述下游节点的动态响应特性

## 积分延迟零点形式参数分析

每个传递函数采用积分延迟零点形式：

```
G_ij(s) = (τ_ij·s + 1) · exp(-T_ij·s) / (α_ij·s + 1)
```

### 参数物理意义
- **τ_ij**：零点时间常数，控制系统的超调和振荡特性
- **T_ij**：延迟时间，描述信号传播的纯延迟
- **α_ij**：极点时间常数，控制系统的响应速度和稳定性

### 参数对系统响应的影响
- τ值越大，系统超调越明显，响应越振荡
- T值决定信号传播的延迟时间，直接影响响应的起始时刻
- α值越大，系统响应越缓慢，但稳定性越好
- 当α > τ时，系统稳定；当α ≤ τ时，系统可能出现不稳定振荡

## 非线性系统的平衡点线性化

### 线性化机理
模型在平衡点附近进行线性化处理：
- 输入扰动：`ΔQ_up = Q_in_up - Q0_up`
- 输入扰动：`ΔQ_down = Q_in_down - Q0_down`
- 输出响应：传递函数矩阵作用于扰动向量
- 最终输出：线性响应 + 平衡点偏移

### 平衡点定义
四方程IDZ模型摒弃传统简化假设，直接基于稳态流量与水位值确定平衡点：
- **输入**：稳态条件 `(Q0_up, H0_up, Q0_down, H0_down)`
- **输出**：对应的平衡蓄量 `V0 = f(Q0, H0)`
- **特点**：无额外假设，完全基于物理关系

## Q-H耦合模式下平衡蓄量计算

### 计算模式
1. **Q-H耦合模式**（推荐）:
   ```python
   V0 = QH_to_V_func(Q_avg, H_avg)
   ```
   其中 `Q_avg = (Q0_up + Q0_down)/2`, `H_avg = (H0_up + H0_down)/2`

2. **传统V-H模式**（兼容）:
   ```python
   V0 = V_from_H_func(H_avg)
   ```

### 计算方法
- 几何中心法：取流量和水位范围的几何中心
- 加权中心法：基于物理重要性的加权平均
- 最优中心法：最小化区间内最大误差的最优点

## 系统稳定性条件与参数设计原则

### 稳定性条件
- **核心条件**：α > τ（保证系统稳定性）
- **物理意义**：极点时间常数必须大于零点时间常数
- **数学依据**：确保传递函数的极点位于s平面左半部

### 参数设计原则
1. **延迟时间设计**：
   ```
   T11 = 0      # 上游本地响应，无延迟
   T12 > 0      # 回水效应，中等延迟
   T21 > T12    # 正向传播，最大延迟  
   T22 = 0      # 下游本地响应，无延迟
   ```
   推荐比例：`T21 : T12 : T11 : T22 = 2 : 1 : 0 : 0`

2. **时间常数设计**：
   - τ范围：60-300秒，主传播路径（G21）可取较大值
   - α范围：200-600秒，保证α > τ的稳定性约束

3. **参数关系**：
   ```
   α11, α22 ∈ [200, 400]    # 本地响应，中等速度
   α12, α21 ∈ [300, 600]    # 传播响应，较慢速度
   τ_ij < α_ij             # 稳定性约束
   ```
