## IDZ模型辨识数据类型与格式要求

IDZ模型参数辨识需要特定类型的阶跃响应数据，这些数据必须包含系统在受到阶跃输入扰动后的动态响应信息。根据`idz_model_identification.py`中的实现，所需数据类型和格式要求如下：

- **数据类型**：时间序列数据，包含输入阶跃和系统输出响应的配对记录。
- **输入数据**：阶跃输入的幅值和发生时间，例如上游流量从30m³/s突增至50m³/s（幅值为20.0）或下游水位从101.0m突增至101.5m（幅值为0.5）。
- **输出数据**：系统对阶跃输入的响应，如水位(m)或流量(m³/s)随时间的变化。
- **时间数据**：以分钟为单位的时间戳，记录从阶跃发生前到达到新稳态的完整过程。
- **结构化格式**：数据应存储在CSV文件中，包含以下列：`场景`、`断面`、`里程(km)`、`时间(分钟)`、`水位(m)`、`流量(m³/s)`。

## 阶跃响应数据准备流程

准备阶跃响应数据是IDZ模型辨识的关键步骤，主要包括时间序列对齐、输入幅值归一化和初始状态处理。这些步骤在`idz_model_identification.py`的`load_step_response_data`和`preprocess_step_response`函数中实现。

### 时间序列对齐

时间序列对齐确保所有数据点的时间基准一致。在`load_step_response_data`函数中，通过读取CSV文件并按`场景`和`断面`分组，然后对每个分组的数据按`时间(分钟)`排序，实现时间对齐。

```python
df = pd.read_csv(csv_file, encoding='utf-8-sig')
scenarios = df['场景'].unique()
sections = df['断面'].unique()
step_data = {}
for scenario in scenarios:
    step_data[scenario] = {}
    for section in sections:
        mask = (df['场景'] == scenario) & (df['断面'] == section)
        section_data = df[mask].copy()
        if len(section_data) > 0:
            step_data[scenario][section] = section_data.sort_values('时间(分钟)')
```

### 输入幅值归一化

输入幅值归一化将输出响应除以输入阶跃的幅值，使辨识出的模型增益K具有物理意义。在`preprocess_step_response`函数中，首先计算响应变化量（输出数据减去初始值），然后除以输入幅值。

```python
time_normalized = time_data - time_data.iloc[0]
initial_value = output_data.iloc[0]
response = output_data - initial_value
if abs(input_magnitude) > 1e-6:
    normalized_response = response / input_magnitude
else:
    normalized_response = response
return time_normalized.values, normalized_response.values
```

### 初始状态处理

初始状态处理涉及确定阶跃发生前系统的稳态值。在`preprocess_step_response`函数中，使用`output_data.iloc[0]`作为初始值，计算响应变化量。这确保了响应数据是从零开始的相对变化。

## 数据质量要求

高质量的数据是成功进行IDZ模型辨识的基础。根据代码实现和分析报告，数据质量要求包括最小数据点数和信噪比。

### 最小数据点数

为了确保模型辨识的准确性，每个场景和断面的数据点数必须足够。在`identify_models_for_scenario`函数中，如果数据点少于4个，则跳过该断面的辨识。

```python
if len(t) < 4:  # 数据点太少
    continue
```

### 信噪比

虽然代码中没有直接计算信噪比，但通过`calculate_r_squared`函数计算决定系数R²来评估拟合质量。高R²值（接近1.0）表明数据信噪比高，模型拟合效果好。

```python
def calculate_r_squared(self, y_true, y_pred):
    ss_res = np.sum((y_true - y_pred) ** 2)
    ss_tot = np.sum((y_true - np.mean(y_true)) ** 2)
    return 1 - (ss_res / ss_tot) if ss_tot > 0 else 0
```

## 数据预处理步骤

数据预处理是将原始数据转换为可用于模型辨识的标准化数据的关键步骤，包括去趋势和滤波。

### 去趋势

去趋势通过减去初始值来消除数据中的稳态偏移，使响应数据从零开始。这在`preprocess_step_response`函数中实现。

```python
initial_value = output_data.iloc[0]
response = output_data - initial_value
```

### 滤波

虽然代码中没有显式的滤波步骤，但通过归一化和模型拟合过程，间接实现了噪声的抑制。高斯滤波或移动平均滤波可以作为预处理步骤添加，以进一步提高数据质量。

## 从原始数据到标准化数据集的转换案例

结合`IDZ模型辨识综合分析报告.md`中的案例，展示从原始仿真输出到可用于辨识的标准化数据集的转换流程。

### 原始数据生成

原始数据由`create_time_data.py`生成，基于非恒定流仿真结果。该脚本读取`阶跃响应对比数据.csv`，并为每个关键时刻生成数据点。

```python
df = pd.read_csv(csv_file, encoding='utf-8-sig')
key_times = [0, 2, 5, 8, 10, 15, 20, 30]
```

### 标准化数据集

生成的`各断面时间序列详细数据.csv`包含3种场景（上游正阶跃、上游负阶跃、下游水位阶跃）、5个断面的详细数据。每个数据点包含时间、水位、流量和状态信息。

### 转换流程

1. **数据读取**：使用`load_step_response_data`读取CSV文件。
2. **数据分组**：按场景和断面分组。
3. **时间对齐**：对每个分组的数据按时间排序。
4. **预处理**：使用`preprocess_step_response`进行时间归一化、响应计算和归一化。
5. **模型辨识**：使用处理后的数据进行一阶或二阶模型辨识。
