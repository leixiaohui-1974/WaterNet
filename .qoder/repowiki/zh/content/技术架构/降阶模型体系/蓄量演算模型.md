## 引言
蓄量演算模型（StorageRoutingModel）是一种基于物理守恒定律的集总参数水文模型，用于模拟具有显著蓄水特性的渠道或水库的调蓄过程。该模型通过求解蓄量连续性方程，并结合蓄量-水位（V-H）和水位-出流（H-Q）的物理关系曲线，能够准确反映非线性水力过程。与经验性模型相比，其参数具有明确的物理意义，适用于水库调度、洪水演进等工程场景。

## 核心建模思想
蓄量演算模型的核心建模思想是将复杂的水力系统简化为一个集总参数系统，其动态行为由三个基本方程描述：

1.  **蓄量连续性方程**：`dV/dt = Q_in - Q_out`
    该方程是质量守恒定律在水文系统中的直接体现，表明系统内蓄水量的变化率等于入流与出流的差值。

2.  **蓄量-水位关系**：`V = f(H)`
    该函数描述了系统的几何特性，即蓄水量与水位之间的非线性关系。对于水库，这通常表现为库容曲线；对于渠道，这取决于断面形状和坡度。

3.  **水位-出流关系**：`Q_out = g(H)`
    该函数描述了系统的出流特性，即出流量与水位之间的关系。对于堰、闸等控制建筑物，这通常由水力学公式（如堰流公式）确定。

这种集总参数建模方法将空间分布的水力过程（如圣维南方程）简化为一个零维的“黑箱”或“蓄水池”，通过物理关系函数将水力状态与渠道几何形状关联，从而在保证物理意义明确的同时，大幅降低了计算复杂度。

## 迭代求解过程
模型的`step()`方法是其核心，它采用预估-校正的迭代求解过程来处理连续性方程中的非线性问题。由于出流量`Q_out`是水位`H`的函数，而水位`H`又是蓄水量`V`的函数，因此在每个时间步长内，新的蓄水量和出流量是相互耦合的，无法直接求解。

该迭代过程如下：

1.  **初始化**：以当前时刻的出流量`Q_out_current`作为时步末出流量的初始估计值。
2.  **迭代循环**：进行固定次数（代码中为3次）的迭代：
    *   **计算平均流量**：使用当前估计的时步末出流量`Q_out_current`和当前时刻的出流量`current_Q_out`，计算平均出流量`Q_out_avg`。入流`Q_in`在时步内被视为恒定，因此`Q_in_avg = Q_in`。
    *   **预估新蓄量**：根据连续性方程，使用平均入流和平均出流计算新的蓄水量`new_V`。
    *   **计算新状态**：利用`V_to_H_func`将新的蓄水量`new_V`转换为新的水位`new_H`，再利用`H_to_Q_func`将新的水位`new_H`转换为新的出流量`Q_out_current`。
3.  **更新状态**：迭代结束后，使用最终的`Q_out_current`和`current_Q_out`计算平均出流量`Q_out_avg`，并调用`_update_physical_states()`方法，根据`Q_in_avg`和`Q_out_avg`更新模型的内部物理状态（蓄水量、水位、时间）。
4.  **返回结果**：返回包含新出流量、水位、蓄水量和时间的字典。

这种迭代方法通过使用平均流量来近似时步内的流量变化，有效解决了非线性方程的求解问题，确保了计算的稳定性和精度。

## 物理关系函数
模型通过`V_to_H_func`和`H_to_Q_func`两个可调用函数（`Callable`）将水力状态与渠道的几何形状和出流特性关联起来。这是模型物理意义明确的关键。

*   **`V_to_H_func`**：这是一个用户定义的函数，输入为蓄水量`V`，输出为对应的水位`H`。它直接编码了渠道或水库的几何信息。例如，对于一个矩形断面的渠道，该函数可以表示为 `H = H_base + V / (L * W)`，其中`L`和`W`分别为渠道的长度和宽度。
*   **`H_to_Q_func`**：这是一个用户定义的函数，输入为水位`H`，输出为对应的出流量`Q_out`。它编码了出流控制结构的水力学特性。例如，对于一个宽顶堰，该函数可以表示为 `Q = C * B * H^(3/2)`，其中`C`为流量系数，`B`为堰宽。

此外，模型还支持一个更高级的`QH_to_V_func`函数，用于实现Q-H耦合的蓄水量计算。该函数认为蓄水量不仅取决于水位`H`，还受流量`Q`的影响，因为大流量时水面线较陡，相同水位下的蓄水量会小于小流量时的蓄水量。这进一步提升了模型在非恒定流条件下的物理真实性。

## 与马斯京干模型的对比
蓄量演算模型与马斯京干模型是两种截然不同的河道演进模型。

*   **蓄量演算模型**：是**物理性模型**。它直接基于物理守恒定律（连续性方程）和物理关系曲线（V-H, H-Q）进行建模。其参数（V-H和H-Q关系）可以直接通过测量或水力学计算获得，物理意义非常明确。它能够自然地保持系统的非线性特性，因此在大范围流量变化时精度更高。

*   **马斯京干模型**：是**经验性线性模型**。它本质上是圣维南方程在特定平衡点（由`initial_V`指定）附近的线性化近似。其核心是经验公式 `Q_out = C0*Q_in + C1*Q_in_prev + C2*Q_out_prev`，其中系数`C0, C1, C2`由参数`K`（滞时常数）和`x`（权重系数）决定。这些参数通常需要通过历史洪水数据进行率定，缺乏直接的物理对应关系。它假设系统是线性的，因此在远离平衡点的工况下精度会下降。

简而言之，蓄量演算模型“从物理出发”，而马斯京干模型“从经验出发”。前者更精确但需要更多的几何数据，后者更简单但精度受限于线性假设。

## 模型初始化与仿真示例
以下是一个使用`StorageRoutingModel`进行仿真的代码示例框架：

```python
# 1. 定义物理关系函数
def V_to_H(V):
    # 例如：矩形渠道，底高100m，长1000m，宽500m
    return 100.0 + V / (1000.0 * 500.0)

def H_to_Q(H):
    # 例如：宽顶堰出流，堰顶高程100m
    if H <= 100.0:
        return 0.0
    return 30.0 * (H - 100.0) ** 1.5

# 2. 初始化模型
dt = 60.0  # 时间步长，60秒
initial_V = 15000.0  # 初始蓄水量，15000 m³
model = StorageRoutingModel(
    dt=dt,
    initial_V=initial_V,
    V_to_H_func=V_to_H,
    H_to_Q_func=H_to_Q,
    name="MyStorageRoutingModel"
)

# 3. 准备入流序列
Q_in_series = [10.0, 20.0, 30.0, 25.0, 15.0, 10.0]  # 入流过程线 (m³/s)

# 4. 运行仿真
results_df = model.run_simulation(Q_in_series)

# 5. 查看结果
print(results_df)
```

此示例展示了如何通过定义`V_to_H`和`H_to_Q`函数来初始化模型，并使用`run_simulation`方法执行完整的仿真序列。

## 应用场景与优势
蓄量演算模型特别适用于以下场景：

*   **水库调洪演算**：水库的库容曲线（V-H关系）和泄洪设施的泄流曲线（H-Q关系）通常非常明确，是该模型的理想应用场景。
*   **宽浅河道或渠池**：当河道的横断面较宽，且具有明显的蓄水能力时，其调蓄效应可以用此模型准确模拟。
*   **非线性效应显著的工况**：当流量变化范围很大，导致V-H和H-Q关系的非线性特性不可忽略时，该模型比线性模型（如马斯京干）更具优势。

其主要优势包括：
1.  **物理意义明确**：所有参数和函数都具有清晰的物理背景。
2.  **精度高**：保留了非线性关系，模拟结果更符合实际物理过程。
3.  **参数易获取**：V-H和H-Q关系可以通过地形测量和水力学计算获得，无需复杂的率定过程。
4.  **灵活性强**：通过自定义`V_to_H_func`和`H_to_Q_func`，可以模拟各种复杂的几何和出流条件。

## 结论
蓄量演算模型是一种基于物理守恒定律的、物理意义明确的集总参数模型。它通过求解蓄量连续性方程，并结合V-H和H-Q物理关系函数，能够准确模拟渠道或水库的调蓄过程。其`step()`方法采用预估-校正的迭代求解，有效处理了非线性问题。与经验性的马斯京干模型相比，蓄量演算模型直接基于物理关系，避免了线性化假设，因此在大范围变化和非线性效应显著的场景下具有更高的精度和可靠性，是模拟水库调度和宽浅河道的理想选择。
