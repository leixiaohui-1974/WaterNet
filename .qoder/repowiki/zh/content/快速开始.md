## 环境准备与依赖安装

在开始使用WaterNet之前，需要确保Python环境已正确配置，并安装所有必要的依赖包。WaterNet支持Python 3.8及以上版本。

首先，克隆项目仓库并进入项目目录：

```bash
git clone https://github.com/your-username/WaterNet.git
cd WaterNet
```

然后，安装项目所需的依赖包。WaterNet的依赖项列在`requirements.txt`文件中，可以通过以下命令安装：

```bash
pip install -r requirements.txt
```

为了验证安装是否成功，可以运行项目提供的测试脚本：

```bash
python scripts/run_tests.py validate
```

如果所有测试通过，则说明环境配置正确，可以开始使用WaterNet进行水力模型仿真。

## 基础模型加载与仿真运行

WaterNet提供了两种主要的模型类型：圣维南模型和降阶模型。圣维南模型基于完整的圣维南方程组，适用于高精度的物理仿真；降阶模型则通过简化假设实现快速计算，适用于实时仿真和参数估计。

### 圣维南模型创建

圣维南模型的创建需要定义渠道的几何断面信息。每个断面包含里程、底高程、糙率以及面积和水面宽的函数。以下代码展示了如何创建一个简单的矩形断面渠道：

```python
sections = [
    {
        'mileage': 0.0, 'elevation': 100.0, 'roughness': 0.025,
        'area_func': lambda h: max(0, h - 100) * 10,
        'top_width_func': lambda h: 10 if h > 100 else 0
    },
    {
        'mileage': 1000.0, 'elevation': 99.0, 'roughness': 0.025,
        'area_func': lambda h: max(0, h - 99) * 10,
        'top_width_func': lambda h: 10 if h > 99 else 0
    }
]

sv_model = SaintVenantModel("TestChannel", "upstream", "downstream", sections)
```

### 降阶模型创建

降阶模型的创建需要定义物理关系函数和模型参数。以马斯京干模型为例，需要定义蓄量-水位关系和水位-出流关系：

```python
def V_to_H(V):
    return 99 + V / 10000

def H_to_Q(H):
    return max(0, (H - 99) * 20)

rom_model = MuskingumModel(
    dt=60.0, K=3600.0, x=0.2, initial_V=10000.0,
    V_to_H_func=V_to_H, H_to_Q_func=H_to_Q
)
```

### 仿真运行

创建模型后，可以使用`run_simulation`方法进行非恒定流仿真。该方法接受一个入流时间序列作为输入，并返回包含出流、水位和蓄水量的仿真结果：

```python
Q_in_series = np.array([8.0, 12.0, 16.0, 12.0, 8.0])
results = rom_model.run_simulation(Q_in_series)
```

## 简化API使用方法

为了降低使用门槛，WaterNet提供了简化API，允许用户通过一行代码创建常用的降阶模型。这些简化函数基于最佳实践参数，适用于大多数应用场景。

### 创建简化模型

`create_simple_muskingum`函数可以创建一个具有默认参数的马斯京干模型：

```python
from waternet.utils.model_factory import create_simple_muskingum

model = create_simple_muskingum()
```

用户也可以自定义部分参数，而保留其他参数为默认值：

```python
model = create_simple_muskingum(K=1800.0, x=0.3)
```

### 场景驱动模型创建

`create_model_by_scenario`函数可以根据应用场景自动选择合适的模型类型：

```python
from waternet.utils.model_factory import create_model_by_scenario

# 水库调洪场景
reservoir_model = create_model_by_scenario('reservoir')

# 河道预报场景
river_model = create_model_by_scenario('river_forecast')

# 精细控制场景
control_model = create_model_by_scenario('precise_control')
```

### 便捷函数

WaterNet还提供了一些便捷函数，如`quick_muskingum`，可以进一步简化模型创建过程：

```python
from waternet.utils.model_factory import quick_muskingum

model = quick_muskingum()
```

## 常见配置错误与解决方案

在使用WaterNet时，可能会遇到一些常见的配置错误。以下是几个典型问题及其解决方案。

### 断面数据不足

创建圣维南模型时，至少需要两个断面。如果断面数量不足，会抛出`ValueError`：

```python
ValueError: 至少需要2个断面来定义明渠
```

**解决方案**：确保`sections`列表中包含至少两个断面的定义。

### 参数范围错误

马斯京干模型的权重系数`x`必须在[0, 0.5]范围内。如果超出此范围，会抛出`ValueError`：

```python
ValueError: 权重系数x必须在[0, 0.5]范围内，得到: 0.6
```

**解决方案**：将`x`参数调整到有效范围内。

### 物理关系函数错误

物理关系函数（如`V_to_H_func`和`H_to_Q_func`）必须是可调用的函数。如果传递了非函数对象，会抛出`ValueError`：

```python
ValueError: V_to_H_func必须是可调用函数
```

**解决方案**：确保传递给模型的物理关系参数是有效的函数。

## 代码示例与预期输出

以下是一个完整的代码示例，演示了如何使用WaterNet进行基础仿真。

```python
import numpy as np
from waternet.models import SaintVenantModel, MuskingumModel
from waternet.config import ConfigManager

# 创建圣维南模型
sections = [
    {'mileage': 0, 'elevation': 100.0, 'roughness': 0.025, 
     'area_func': lambda h: max(0, h-100)*10, 
     'top_width_func': lambda h: 10 if h > 100 else 0},
    {'mileage': 1000, 'elevation': 99.0, 'roughness': 0.025,
     'area_func': lambda h: max(0, h-99)*10,
     'top_width_func': lambda h: 10 if h > 99 else 0}
]

sv_model = SaintVenantModel("TestChannel", "upstream", "downstream", sections)

# 创建降阶模型
def V_to_H(V):
    return 99 + V / 10000

def H_to_Q(H):
    return (H-99)**1.5 * 100

rom_model = MuskingumModel(dt=60.0, K=3600, x=0.2, initial_V=50000,
                          V_to_H_func=V_to_H, H_to_Q_func=H_to_Q)

# 运行仿真
Q_in_series = np.ones(100) * 10.0
results = rom_model.run_simulation(Q_in_series)

print(results.head())
```
