## 简介

本安装指南旨在为用户提供WaterNet框架的完整安装说明。WaterNet是一个基于圣维南方程组的明渠水力模型数字孪生建模框架，专为水利工程的数值仿真和参数估计而设计。本指南将详细介绍多种安装方式、外部依赖要求、虚拟环境配置建议以及安装验证方法，确保用户能够顺利安装和使用WaterNet。

## 系统要求

在安装WaterNet之前，请确保您的系统满足以下要求：

- **操作系统**: Windows, Linux, macOS
- **Python版本**: 3.8或更高版本
- **内存**: 建议至少4GB RAM
- **磁盘空间**: 至少500MB可用空间

WaterNet框架对Python版本有明确要求，必须使用Python 3.8或更高版本。较低版本的Python可能无法正确运行框架中的某些功能。

## 外部依赖

WaterNet依赖于多个外部库来实现其功能。这些依赖分为核心依赖和可选依赖，具体如下：

### 核心依赖

核心依赖是WaterNet正常运行所必需的库，包括：

- **NumPy**: 版本 >= 1.20.0
- **Pandas**: 版本 >= 1.3.0
- **SciPy**: 版本 >= 1.7.0
- **Matplotlib**: 版本 >= 3.4.0

这些依赖在`pyproject.toml`和`requirements.txt`文件中都有明确声明，确保了跨平台的一致性。

### 可选依赖

可选依赖提供了额外的功能，根据需要选择安装：

- **机器学习**: scikit-learn >= 1.0.0
- **优化**: cvxpy >= 1.2.0
- **测试**: pytest >= 6.0.0, pytest-cov >= 2.12.0
- **文档**: sphinx >= 4.0.0, numpydoc >= 1.1.0

可选依赖通过`pyproject.toml`中的`optional-dependencies`字段进行管理，用户可以根据需要安装特定的功能模块。

## 安装方式

WaterNet支持多种安装方式，用户可以根据自己的需求和环境选择最适合的方法。

### pip安装

使用pip安装是最简单和推荐的方式。您可以通过以下命令安装WaterNet：

```bash
# 从PyPI安装
pip install waternet

# 或者从源码安装
pip install -e .
```

对于需要完整功能的用户，可以使用以下命令安装所有可选依赖：

```bash
pip install -e ".[dev]"
```

### 源码安装

如果您希望从源码安装WaterNet，可以按照以下步骤操作：

1. 克隆仓库：
```bash
git clone https://github.com/waternet/waternet.git
cd waternet
```

2. 安装依赖：
```bash
pip install -r requirements.txt
```

3. 安装WaterNet：
```bash
pip install -e .
```

源码安装方式适合希望对代码进行修改或贡献的开发者。

## 虚拟环境配置

为了确保WaterNet的安装和运行环境的隔离性，强烈建议使用虚拟环境。以下是配置虚拟环境的步骤：

### 创建虚拟环境

```bash
# 使用venv创建虚拟环境
python -m venv waternet-env

# 激活虚拟环境
# Windows
waternet-env\Scripts\activate
# Linux/macOS
source waternet-env/bin/activate
```

### 安装依赖

在激活的虚拟环境中，按照上述安装方式安装WaterNet及其依赖。

使用虚拟环境可以避免与其他Python项目的依赖冲突，确保WaterNet的稳定运行。

## 安装验证

安装完成后，建议运行验证脚本来确保WaterNet正确安装并可以正常工作。

### 运行验证脚本

WaterNet提供了一个专门的验证脚本`validate_install.py`，用于检查安装的完整性。运行方法如下：

```bash
python scripts/validate_install.py
```

该脚本将执行以下检查：

1. **Python版本**: 检查Python版本是否符合要求
2. **依赖包**: 检查所有必需的依赖包是否已正确安装
3. **模块导入**: 测试WaterNet核心模块是否可以正常导入
4. **基本功能**: 测试圣维南模型、马斯京干模型等基本功能
5. **示例脚本**: 检查示例脚本是否存在
6. **配置文件**: 验证配置文件格式是否正确

### 验证结果

验证脚本将输出详细的检查结果，包括通过和失败的项目。如果所有检查都通过，您将看到类似以下的输出：

```
🎉 所有验证通过，WaterNet安装成功！

🚀 现在您可以:
   - 运行示例程序: python examples/basic_usage.py
   - 阅读文档了解更多功能
   - 开始您的建模工作
```

如果存在失败的项目，脚本将提供相应的错误信息和解决建议。

## 常见问题排查

在安装和使用WaterNet过程中，可能会遇到一些常见问题。以下是常见问题及其解决方法：

### 依赖冲突

如果在安装过程中遇到依赖冲突，建议使用虚拟环境来隔离依赖。您也可以尝试更新pip到最新版本：

```bash
pip install --upgrade pip
```

### 编译错误

某些依赖包可能需要编译，如果遇到编译错误，请确保系统已安装必要的编译工具：

- **Windows**: 安装Microsoft Visual C++ Build Tools
- **Linux**: 安装build-essential包
- **macOS**: 安装Xcode命令行工具

### 缺失动态链接库

如果遇到缺失动态链接库的错误，可能是系统缺少必要的运行时库。请根据操作系统安装相应的运行时库：

- **Windows**: 安装Microsoft Visual C++ Redistributable
- **Linux**: 安装libgcc和libstdc++库
- **macOS**: 确保Xcode命令行工具已正确安装

### 其他问题

如果遇到其他问题，建议查看`README.md`文件中的详细说明，或在GitHub Issues中搜索类似问题。您也可以联系开发团队获取帮助。
