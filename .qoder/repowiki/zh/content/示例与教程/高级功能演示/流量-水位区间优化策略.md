## 系统概述

本系统基于流量-水位关系的区间划分优化方法，旨在通过自动化的区间分割和动态调整机制，提高水文模拟的精度和效率。系统核心包括五区间自动分割算法、区间管理器、性能监控模块等，能够根据不同工况灵活调整分区策略，确保模型在各种条件下均能保持高精度。

## 五区间自动分割算法

### 配置与执行过程

五区间自动分割算法通过`demo_five_intervals.py`脚本实现，主要步骤如下：

1. **创建代表性区间**：根据`README.md`文档要求，创建五个具有代表性的流量-水位区间，每个区间都有明确的流量范围、水位范围和平衡点。
2. **生成IDZ参数**：基于每个区间的特性，生成相应的IDZ（Input-Dependent Zone）模型参数，包括增益K、时间常数τ和延迟T。
3. **创建阶跃响应模拟方案**：为每个区间创建阶跃响应模拟方案，用于验证模型的动态响应特性。

### 算法实现细节

- **区间定义**：每个区间由`FlowStageInterval`类定义，包含区间ID、名称、流量范围、水位范围、平衡点和特征描述。
- **参数生成**：通过`generate_idz_parameters`函数生成IDZ模型参数，这些参数基于区间的流量和水位特性进行计算。
- **模拟方案**：通过`create_step_response_simulation_plan`函数创建阶跃响应模拟方案，包括步长、模拟时长、时间步长等参数。

## 区间管理器内部状态机设计

### 状态机设计

区间管理器（`IntervalManager`）负责运行时的区间选择和切换，支持平滑过渡和性能优化。其内部状态机设计包括以下几个关键组件：

1. **状态管理**：管理当前区间、前一个区间和过渡状态。
2. **性能缓存**：缓存过渡响应和过渡历史，提高性能。
3. **预测和平滑**：支持轨迹预测和边界平滑，确保系统稳定性。


### 状态机操作

- **选择活跃区间**：根据当前流量和水位选择最合适的区间。
- **平滑过渡**：在区间切换时，实现平滑过渡，避免突变。
- **更新数据库**：更新区间数据库，确保数据一致性。

```python
def select_active_interval(self, current_Q: float, current_H: float) -> Optional[FlowStageInterval]:
    """
    选择当前活跃区间
    
    Args:
        current_Q: 当前流量
        current_H: 当前水位
        
    Returns:
        FlowStageInterval: 选中的区间，如果没有合适区间则返回None
    """
    # 优先检查当前区间是否仍然适用
    if (self.current_interval and 
        self.current_interval.contains_point(current_Q, current_H)):
        return self.current_interval
    
    # 查找包含当前点的区间
    containing_interval = self.database.find_containing_interval(current_Q, current_H)
    
    if containing_interval:
        # 检查是否需要切换
        if containing_interval != self.current_interval:
            self._prepare_transition(containing_interval, current_Q, current_H)
        
        return containing_interval
    
    # 如果没有直接包含的区间，寻找最近的区间
    nearest_interval = self._find_nearest_interval(current_Q, current_H)
    
    if nearest_interval:
        distance = self._compute_distance_to_interval(current_Q, current_H, nearest_interval)
        
        # 如果距离在可接受范围内，使用最近区间
        if distance <= self.config.overlap_tolerance:
            if nearest_interval != self.current_interval:
                self._prepare_transition(nearest_interval, current_Q, current_H)
            
            return nearest_interval
    
    # 没有找到合适的区间
    self.logger.warning(f"未找到适合点 ({current_Q:.2f}, {current_H:.3f}) 的区间")
    return None
```

```python
def setup_integrated_system(self, channel_config: FiveSectionConfig,
                           optimizer_config: Optional[OptimizerConfig] = None) -> Tuple[SaintVenantModel, FlowStageIntervalOptimizer]:
    """
    设置集成系统
    
    Args:
        channel_config: 渠道配置
        optimizer_config: 优化器配置
        
    Returns:
        Tuple: (圣维南模型, 区间优化器)

    self.logger.info("集成系统设置完成")
    
    return saint_venant, optimizer
```

## 分区结果可视化方法

### 可视化方法

分区结果可视化通过`visualize_intervals`方法实现，支持将区间划分结果以图形形式展示。该方法使用`matplotlib`库绘制矩形区域，每个区域的颜色表示其质量评分。

```python
def visualize_intervals(self, intervals: List[FlowStageInterval], 
                      filepath: Optional[str] = None) -> None:
    """可视化区间划分结果"""
    if not intervals:
        return
    
    fig, ax = plt.subplots(figsize=(10, 8))
    
    colors = [interval.quality_score for interval in intervals]
    max_color = max(colors) if colors else 1.0
    
    for i, interval in enumerate(intervals):
        Q_min, Q_max = interval.Q_bounds
        H_min, H_max = interval.H_bounds
        
        color_val = colors[i] / max_color if max_color > 0 else 0
        rect = plt.Rectangle((Q_min, H_min), Q_max - Q_min, H_max - H_min,
```

### 汛期/枯水期模式切换

- **枯水期**：流量小，水位低，响应特性线性度高，适合作为基准区间。

## 配置参数调优建议

### 参数调优

为了确保系统在不同工况下均能保持高精度，需要对配置参数进行调优。以下是一些建议：

1. **误差阈值**：根据实际需求调整误差阈值，确保模型精度满足要求。
2. **初始网格大小**：根据流量和水位范围选择合适的初始网格大小，避免过度细分或细分不足。
3. **最大细分层级**：根据计算资源和精度要求，合理设置最大细分层级。
4. **合并相似区间**：启用合并相似区间功能，减少区间数量，提高计算效率。
