## 一、Jacobian矩阵数值scaling优化

### 1.1 实现的四种策略

#### 物理量纲scaling (Physics-Based Scaling)
- **原理**: 基于圣维南方程物理量纲构建scaling矩阵
- **连续性方程scaling**: [L³/T]/[L] = [L²/T]
- **动量方程scaling**: [L²/T²]
- **效果**: 矩阵条件数改善有限，残差从1.30e+03降至较低水平

```python
# 核心实现
row_scales[i] = 1.0 / (flow_scale / length_scale)  # 连续性方程
row_scales[i] = 1.0 / velocity_scale**2            # 动量方程
```

#### 平衡缩放 (Equilibration Scaling)
- **原理**: 基于行列范数的平衡化技术
- **算法**: 迭代调整行列scaling使得行列范数趋于平衡
- **效果**: 矩阵条件改善效果最佳，残差降至2.54e+00
- **优化统计**: matrix_conditioned=29次，说明需要频繁调整

#### 几何缩放 (Geometric Scaling)
- **原理**: 基于矩阵几何性质的scaling
- **效果**: 残差较高(3.12e+04)，适应性调整频繁
- **特点**: timestep_adapted=8次，需要更多时间步调整

#### 迭代缩放 (Iterative Scaling)
- **原理**: 在迭代过程中动态调整scaling
- **效果**: 最终残差最低(9.35e-01)，但需要最多矩阵调整
- **优化统计**: matrix_conditioned=116次，计算成本最高

## 二、自适应时间步长控制

### 2.1 控制机制

#### CFL条件约束
```python
if cfl_number > cfl_target:
    dt_cfl = current_dt * cfl_target / cfl_number * safety_factor
```
- **目标CFL**: 0.5
- **安全因子**: 0.8
- **效果**: 确保数值稳定性

#### 收敛性分析
- **发散检测**: 残差增长率 > 2.0 → 减小时间步
- **快速收敛**: 残差减少率 > 0.5 → 增大时间步  
- **停滞检测**: 改善率 < 1e-3 → 轻微减小

#### 迭代次数控制
- **过多迭代** (>15次): 时间步×0.8
- **快速收敛** (<5次): 时间步×1.1

### 4.2 失败原因分析

#### 根本问题
1. **基础数值格式的局限性**: Preissmann四点隐式差分在当前网格和边界条件下固有的数值困难
2. **初始条件敏感性**: 最小流速警告(0.049-0.096m/s)表明初始条件接近数值边界
3. **矩阵条件数过大**: 尽管有scaling优化，条件数仍在1e12以上

#### 具体技术问题
1. **Scaling策略的限制**: 虽然降低了残差，但未解决根本的条件数问题
2. **时间步控制的保守性**: 频繁的时间步调整反映了数值刚性
3. **松弛因子的边界约束**: 最小松弛因子0.01限制了进一步的稳定化
